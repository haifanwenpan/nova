# nova H.264/AVC Baseline 解码器 —— 学习文档

> 对象：OpenCores `nova` 项目（Ke Xu, 2008），H.264/AVC Baseline Profile 解码器，
> QCIF 176×144，Verilog 25,826 行（`src/` 下 52 个 `.v` 文件）。
>

## 三句话概括这个 IP

1. **它不是通用产品解码器，而是一篇低功耗博士论文的硅验证载体。** 作者 Ke Xu（2007/2008）的每一个低功耗手法在 RTL 里都能逐行对上号：Gray 码层次状态机、2/4/10 分层前导 1 检测、查表替代除法、移位替代乘法、三级操作数隔离、单端口 SRAM 五级去块流水、39 路锁存器时钟门控。
2. **它的性能数字干净且可复现。** 论文说去块滤波稳态 204 cycles/MB，iverilog 与波形实测每个 MB 精确 **209 cycles**（+5 拍流水填充/状态清零，`gclk_DF` 为 210 拍）；300 帧 `akiyo` 实测均值 **49,954 cycles/帧**（×30 fps = **1.50 MHz**），与规格书完美吻合；且单 MB 解码速度与 `freq_ctrl` 档位完全正交。
3. **它只实现了 Baseline 的一个窄子集，且分辨率写死为 QCIF。** SPS 解析器硬连线假设 `pic_order_cnt_type == 0` 且 `vui == 0`，NAL 分发缺少 `default` 分支（遇 SEI/AUD 死锁），FSM 的 `slice_type` 只认 `5/7` —— 详见 [第 10 章](10-兼容性陷阱与移植指南.md)。

## 已验证的事实（本文档的可信度来源）

| 验证项 | 方法 | 结果 |
|---|---|---|
| 功能正确性 | iverilog 跑 300 帧 akiyo QCIF，与 ffmpeg 逐像素比对 | **300/300 帧比特精确（11,404,800 像素零差异，PSNR = ∞）** |
| 去块滤波周期 | 波形 + 探针测 `DF_duration` 高电平宽度 | **每 MB 精确 209 cycles**（零方差；论文稳态 204） |
| 整帧周期 | testbench 统计（300 帧） | **49,954 cycles/帧**（× 30 = 1.50 MHz） |
| 变频档位 | `freq_ctrl[1:0]` 四档实测（14 帧） | `cf0/cf1` 精确 **45,004 / 50,004** 增量（`cf2/cf3` 受 TB `IDLE_FLUSH=20000` 提前触发） |
| MB 级速度 | P 帧探针 / 首帧 IDR 波形实测 | P 帧均值 **~330 cycles/MB**；IDR 帧中位 **396.5** / 均值 **423.1 cycles/MB** |
| MB 类型差异 | 按 `mb_type_general` 分类统计 | P_skip **326** / Inter16×16 **422** / P_8×8 **515 cycles/MB** |
| 速率控制下限 | 二分法改 `cycles_per_frame0` | akiyo 真实需求 **42,100**（由第 1 帧 IDR 决定；出厂 45,000，余量 6.4%） |
| 去块滤波效果 | `+nodb` 关掉 DF 对比 | 40% 像素变化，PSNR 从 ∞ 降到 **46.35 dB**（maxdiff = 24） |
| x264 兼容性 | 用 ffmpeg 生成 baseline 码流 | **FAIL（PSNR 4.93 dB）**，根因见 [第 10 章](10-兼容性陷阱与移植指南.md) |

## 目录速查

- `src/` —— 原始 RTL（**52 个 `.v`，25,826 行，不要直接改**，仿真用 `sim/rtl/` 副本）
- `doc/nova_spec.doc` —— 原始规格书（Word 97 格式），正文提取在 `learn/doc_extract/nova_spec.txt`
- `test/bitstream/akiyo300_1ref.txt` —— 随 IP 附带的 JM94 编码码流（300 帧 QCIF）
- `sim/` —— 本机 iverilog 仿真与回归环境（见 [第 9 章](09-仿真环境与ffmpeg对比.md)）
  - `sim/rtl/` —— `src/` 副本 + `setup_rtl.sh` 打上的 3 处补丁
  - `sim/tb/tb_nova.v` —— 自写 testbench，直接输出标准 YUV420p 与可选 VCD/FST 波形
  - `sim/scripts/run_regression.sh` —— 一键六步回归（准备码流 → ffmpeg 参考 → 编译 → 仿真 → 逐像素比对 → 帧数校验）
